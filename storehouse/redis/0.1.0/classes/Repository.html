    fetch

    • fetch<P extends RedisVariadicArgument | undefined = undefined>(
          id: RedisArgument,
          options?: JsonGetOptions & { path?: P },
      ): Promise<GetPathType<JsonDocument<TSchema>, P> | null>

      Fetches a JSON Document, or part of it, from Redis by its id.

      The shape of the result depends on options.path:

      • no path or .: the whole JSON Document, validated against the schema.
      • $: the whole JSON Document wrapped in an array (RedisJSON 2.x JSONPath reply). The document is validated against the schema.
      • any other JSONPath (starting with $): an array of the matches, exactly as returned by Redis (empty if nothing matches). It is not validated.
      • any other path (legacy syntax, such as .artist or artist): the value at that path, as returned by Redis. It is not validated.

      Type Parameters

      • P extends RedisVariadicArgument | undefined = undefined

      Parameters

      • id: RedisArgument

        the id of the JSON Document to fetch

      • Optionaloptions: JsonGetOptions & { path?: P }

        optional JSON.GET command options

      Returns Promise<GetPathType<JsonDocument<TSchema>, P> | null>

      the result described above, or null if the JSON Document does not exist

      Throws

      ValidationError if the JSON Document is validated and does not conform to the schema
