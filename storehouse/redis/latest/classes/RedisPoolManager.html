    run

    • run<R>(operation: () => Promise<R>): Promise<R>

      Executes an asynchronous operation with the Redis connection, ensuring that the connection is open, and enforcing a command timeout.

      Because node-redis' own command timeout stops once the command is written to the socket, so it does not protect against a frozen Redis.

      This method adds an additional layer of protection by enforcing a command timeout at the application level.

      The value of the command timeout is taken from the options provided during the client's initialization (commandOptions.timeout) or defaults to 5000 milliseconds if not specified.

      Type Parameters

      • R

      Parameters

      Returns Promise<R>

      A promise that resolves to the result of the operation or rejects with an error if the operation fails or times out

      Throws

      If the Redis connection is not open

      Throws

      If the operation exceeds the configured command timeout
